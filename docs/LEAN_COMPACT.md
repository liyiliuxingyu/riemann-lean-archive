## 简化方法与接口保持

这项简化采用上游对背景库与核心论证的整套重写。共享规模估计、主不等式输入接口及 Mathlib 引理减少重复展开；五个公开陈述不变，内部模块名和证明路径大幅调整。全部 794 个模块仍在 Main 的导入闭包中，没有通过“未被 Main 导入”这一规则进一步删除模块。

原版、上游可读版及紧凑版的 `Statements.lean` 逐字节一致，Git blob 均为 `1cd1bce93344065936b2b392b23306254e0785ef`。公开出口仍覆盖 Mathlib 的 RH、ζ 的非平凡零点、任意 Dirichlet 特征在右半平面的非零性和开临界带零点，以及原始特征的特例。极点排除条件仍为 `χ ≠ 1 ∨ s ≠ 1`；没有把任意特征缩小为仅原始特征。

环境由 Lean 4.33.1 / Mathlib `0df444a3…` 改为独立的 Lean 4.35.0 / Mathlib `56a00585…`。所核对的 RH、ζ、Dirichlet L 函数定义正文未变，但这不等于已证明两套完整环境及所有内部声明等价。

## 实际验证与自动检查

- 逐文件来源哈希、构建配置、无环导入图、Main 全模块闭包及生产源静态检查已通过。
- 独立接口验收器的纯 Lean 元数据检查及六个负例已在本机编译检查。
- 本机官方 Lean 4.35.0 的下载 SHA-256、运行版本和九个固定依赖已核对；完整 Mathlib 缓存因磁盘不足退出，未在本机完成 Main 构建或最终五项公理检查。
- 仓库工作流会实际执行完整构建、五项类型验收和公理白名单检查，结果与日志作为小型 artifact 保存。没有启用收费的大型 runner，没有上传 GB 级缓存或编译产物。

自动检查先在只含官方 Mathlib 的环境中形成预期陈述，再检查编译产物的实际 `ConstantInfo` 和内核类型赋值，拒绝附加参数、声明种类变化或白名单外公理。`validation.json` 仅在所有阶段成功后写 `passed: true`。

上游 `Challenge.lean` 的五个 `sorry` 是比较器题面，排除在生产导入闭包和默认目标之外。上游关于 Comparator 或独立内核的检查报告属于上游自述；本轮没有执行这些步骤，也没有完成数学同行评议。旧的 `anyGeometry` 名称没有出现在新实现中，不足以单独证明旧几何争议已解决。
